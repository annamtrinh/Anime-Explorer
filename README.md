
# Anime Explorer

A Java console app for browsing anime by genre, searching by title, filtering by rating, and managing a personal watch list.

## Features
- Browse Action and Romance anime
- Search by title (case-insensitive)
- Filter by minimum rating
- Get a random anime suggestion
- Add shows to a watch list with your own rating

## Concepts Used
- Object-oriented programming (classes, encapsulation, constructors)
- ArrayLists and loops
- Static helper methods (`AnimeLibrary`)
- User input with `Scanner` and input validation with `try/catch`

## How to Run
```
javac *.java
java MyProgram
```
